## About

JXRouter (JXProxy) — a macOS menu-bar proxy app that routes AI API traffic (Claude Code, Codex, OpenAI SDK clients) through configured LLM providers. Native SwiftUI/AppKit, no web admin, no /etc/hosts edits.
## Recent Changes

- 2026-09-06: Mirrored `llama.app` configuration and model presets onto the built-in GGUF model loader (`llama-server`). Identified why Claude Code failed to respond with GGUF models: (1) context window was previously divided into 4 slots via `--parallel 4`, reducing slot context to 32k which caused 80k+ token prompts to immediately abort; (2) `--chat-template chatml` had overridden embedded Jinja templates and broke XML tool-calling and reasoning tokens. Implemented `LlamaModelPresetReader` in `LocalModelManager.swift` to automatically parse `~/.config/llama/models.user.ini` and `~/Library/Application Support/Llama/models.ini`, merging global `[*]` and model-specific configurations. Configured `llama-server` flags to match `llama.app` byte-for-byte: dedicated single-slot allocation (`--parallel 1 --models-max 1`), 128k context size (`-c 131072`), context shifting (`--context-shift`), Flash Attention (`-fa on`), KV cache quantization (`-ctk q8_0/q4_0 -ctv q8_0/q4_0`), memory lock (`--load-mode mlock`), threading (`-t 12 -tb 12`), batching (`-b 2048 -ub 2048`), sampling arguments (`--temp 0.8 --min-p 0.05 --top-p 0.95 --top-k 0 --repeat-penalty 1.05 --repeat-last-n 256 --dry-multiplier 0.8 --dry-base 1.75 --dry-allowed-length 2`), companion Jinja template discovery (`Qwen-Fixed-Chat-Templates` / `MiniCPM5-Fixed-Chat-Templates`), and preset path loading via `--models-preset`. Added port listener cleanup (`killProcessOnPort`) and `forceRestart` support on model runs. Verified end-to-end Claude Code `/v1/messages` execution and streaming XML tool calling through port 5255 -> 8081.
- 2026-09-06: Fixed model selection detection for models loaded via the built-in GGUF model loader (`llama-server`). Added runtime detection in `LocalModelManager` via `/props` and `/v1/models` probes to query active model paths, aliases, and modalities on port 8081. Added GGUF Direct runtime detection to `LocalProviderDetector`. Updated `SettingsView` tier model options (`tierModelOptions` / `fetchTierModels`) to automatically discover, populate, and set the running GGUF model alias across routing tiers (Default/Opus/Sonnet/Haiku) instead of static `local-model`. Synchronized active model selection in `selectGGUFModel()` and `runGGUFModel()` to persist `config.provider = "gguf"`, `config.model`, and `config.ggufModelAlias`.
